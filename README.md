# Nature-Inspired Data Storage Systems

Two interactive labs that run fully in the browser (no install, works offline):

1. **DNA-Based Storage Systems** - type a message, encode it as A/C/G/T, add copying errors, recover it by majority vote across copies.
2. **Genetic Algorithm and its application** - evolve cargo plans for a weight-limited truck (knapsack problem) and compare with the exact best answer.

Open `index.html` to run it.
